# Help test NovaCore

Download TESTER from Releases and open a GitHub issue. No Discord account,
payment or application is required. Please include build/channel, console model,
firmware, exact HEN build, reproduction steps, expected/actual results and error
codes. Attach the matching completed text report if helpful. Pasted details are
welcome in GitHub issues; Discord's bot needs a `.txt` attachment.

Suggestions belong in a feature-request issue. Search existing issues first.
Do not post credentials or private logs. Report reproducible behavior rather
than assumptions about source code. Contributions to this release repository
do not imply ownership of the unpublished app or third-party dependencies.
