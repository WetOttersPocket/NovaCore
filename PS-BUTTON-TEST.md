# DEV PS-button test

TESTER does not enable this experimental route. In DEV, open Settings → Startup
& recovery → PS return. The activation confirmation and result are shown in
Nova. Follow the instructions there; do not press PS after a failed enable.

Once activation succeeds:

1. Short-tap and release PS; observe whether Nova regains focus. A Sony dashboard
   flash may occur. Holding PS is left to Sony's menu.
2. Repeat five short taps with a pause after each return. Record actual results.
3. Only after those pass, launch a game, return, then repeat on Nova Home.
4. Use CoreDeck → Original dashboard and check that Nova does not pull you back.
5. Report build, HEN, errors, successful repeat count and game-transition results.

This is an explicit, time-limited DEV experiment, not a permanent system-menu
replacement. Disable it when finished. Prior ShellUI crashes remain unresolved;
stop on an error and preserve diagnostics rather than forcing another attempt.
