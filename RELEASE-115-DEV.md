# Preview 115 DEV / 5.120

Experimental prerelease for informed testing. Unlike TESTER, this enables the
DEV PS-return code path, plugin/patch configuration editing and DEV catalogue
capabilities. It does not guarantee those features work on a given console.

The PS-return activation confirmation/result appears inside Nova. Read
PS-BUTTON-TEST.md for the repeat, game-transition and deliberate-exit checks.
Session opt-in is not permanent; Sony's dashboard may still flash. The prior
ShellUI crash cause remains unresolved. Do not enable it globally or force past
activation failures. TESTER is the appropriate baseline for ordinary feedback.

DEV and TESTER share NOVA00001 and replace one another. Same revision does not
mean identical capabilities. Use channel-specific report/release notes.
Public availability of a third-party catalogue does not make its packages
NovaCore's content or establish redistribution rights.
