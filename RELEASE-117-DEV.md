# Preview 117 DEV / 5.124

Preview 117 DEV contains the same UI, Game Toolbox, room-name fix, greetings,
Downloading library view, NEXT launcher integration and credit update as TESTER.
It also retains DEV-only Linux Lab, GoldHEN controls and developer integrations.

Important:
- DEV is experimental. Use only package/catalogue sources you own or are
  authorised to distribute.
- Apollo and Itemzflow remain separate apps. Nova detects and launches installed
  copies; it does not embed or repackage their code.
- NEXT remains a separate project/process. Nova launches an installed copy and
  displays the supplied artwork; shared diagnostics await NEXT's documented
  report format.
- PS4 system database rebuilding remains a manual Sony Safe Mode operation.
- PS-button return is experimental and not claimed as permanently working.

DEV and TESTER share title ID `NOVA00001` and replace one another.
